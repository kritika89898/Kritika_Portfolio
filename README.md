# Kritika Bhanaria – Portfolio

Personal portfolio of Kritika Bhanaria, B.Tech Computer Science & AI student at IGDTUW (class of 2027).

**Live:** https://kritika89898.github.io/Kritika_Portfolio/

## What's inside

- **Interactive terminal** in the hero: try `help`, `projects`, `leetcode`, `open examforge`
- **LeetCode heatmap**: submissions over the last year, problems solved, contest rating and streaks
- **Projects** with live links, source code and demo videos, filterable by Full-stack, AI / ML and Frontend
- **Experience** timeline, skills and achievements
- **Skills**, **achievements** and a **contact** form that opens your email app
- Light and dark themes (follows your system setting, remembers your choice)
- Responsive down to small phones, keyboard accessible, respects reduced-motion settings

## Tech

Plain HTML, CSS and JavaScript, no framework or build step. Hosted on GitHub Pages.

```
index.html                            page markup and content
style.css                             design tokens, layout, light/dark themes
script.js                             terminal, project filters, theme toggle, contact form
activity.js                           LeetCode heatmap (reads data/activity.json)
scripts/fetch-activity.mjs            fetches LeetCode activity
.github/workflows/update-activity.yml runs that script every 6 hours and commits the data
data/activity.json                    generated by the workflow, don't edit by hand
assets/                               favicon and project images (WebP / SVG)
```

## How the LeetCode heatmap stays up to date

GitHub Pages only serves static files, and LeetCode doesn't let browsers call its API directly,
so a GitHub Action does the fetching: every 6 hours it pulls the submission calendar, solved
counts and contest rating from LeetCode and commits `data/activity.json`. The page reads that
file. If LeetCode can't be reached, the last good data is kept. To refresh right away:
**Actions → Update LeetCode activity → Run workflow**.

To use a different account, change `LEETCODE_USER` at the top of `scripts/fetch-activity.mjs`.

## Run locally

```bash
python -m http.server 8000
# open http://localhost:8000
```

## Updating a project

Each project is an `<article class="project">` in `index.html`. Add its screenshot to `assets/projects/`,
set `data-tags` to any of `fullstack`, `ml`, `frontend`, and add it to the `projects` list in `script.js`
if it should appear in the terminal too.
